# Wordle - Python 版本

這個專案包含兩種 Wordle 遊戲的實作：

- `gui_wordle.py`：純 Python (tkinter) GUI 版本，採用**單詞選擇模式**，建議在桌面環境直接執行。
- `index.html` + `static/*` + `run_server.py`：瀏覽器版本與簡易本機伺服器（備援）。

功能：

### gui_wordle.py（推薦）

- **遊戲模式**：選擇單詞而非輸入字母。右側顯示 10 個隨機單詞選項（與答案不重複），點擊即可提交該排。
- **答案題庫**：50 個五字英文單詞，每局隨機選擇一個。
- **選項題庫**：50 個獨立的五字英文單詞，每局隨機生成 10 個選項供玩家選擇。單詞選項與預設答案會錯開，不會出現重複。
- **6 排 × 5 格的猜字板**，顏色提示：
  - 綠色（位置正確）
  - 黃色（字母存在但位置錯誤）
  - 灰色（不在答案中）
- **右側選項顯示**：已被猜過的單詞選項會立即變為灰色，方便快速辨識剩餘選項。

### index.html（備援瀏覽器版）

- 支援傳統字母輸入模式
- 右側字母表（4 欄排列）
- 送出後字母立即變灰

## 執行方式

在專案目錄下執行：

```bash
python gui_wordle.py
```

或啟動瀏覽器版本（如需）：

```bash
python run_server.py
# 然後開啟瀏覽器到 http://localhost:8000/index.html
```

## 備註
- `gui_wordle.py` 使用標準庫 `tkinter`，不需額外安裝套件（但在某些最小化的 Python 安裝中可能未包含 GUI 支援）。
